ЧТО ЭТО
───────────────────────────────────────────────────────
Телеграм-бот магазина. Разговаривает живым языком, знает
каталог с ценами и остатками, ведёт корзину и выставляет
счёт с QR-кодом.

Три продавца на выбор, переключаются кнопкой в чате:
  * Кира, 22        — лёгкая, игривая, продаст что угодно
  * Ольга Ивановна  — 30 лет в торговле, скидок не даёт
  * Степан, 35      — свой человек, минус 10 процентов

Работает на бесплатных ключах Google. Когда прилетает
ошибка лимита — сам берёт следующий ключ, а если кончились
все — переходит на модель попроще. Пользователь при этом
не видит ни одной ошибки.


ЧТО НУЖНО
───────────────────────────────────────────────────────
1. Node.js версии 20 или новее     https://nodejs.org
   Скачать LTS, ставить со всеми галочками по умолчанию.

2. Ключи Google (бесплатно, карта не нужна)
   https://aistudio.google.com  →  Get API key

   ВАЖНО: сделайте 2-3 ключа, каждый в СВОЁМ проекте.
   Квота считается на проект, значит три проекта —
   три независимых лимита.

3. Токен бота
   Написать @BotFather в телеграме  →  /newbot
   Скопировать токен ЦЕЛИКОМ, вместе с цифрами
   до двоеточия.


КАК ЗАПУСТИТЬ  (Windows)
───────────────────────────────────────────────────────
Если Windows или антивирус ругнётся на файл УСТАНОВКА.bat
— это нормально. Любой .bat, скачанный из интернета,
вызывает подозрение, потому что внутри команды.
Нажмите "Подробнее" -> "Выполнить в любом случае".

Не хотите запускать .bat — в самом низу этого файла
есть те же действия обычными командами.

Шаг 1.  Двойной клик по файлу       УСТАНОВКА.bat
        Подождать, пока всё поставится.
        В конце сам откроется Блокнот с файлом настроек.

Шаг 2.  В открывшемся файле вписать токен и ключи:

           TG_BOT_TOKEN=сюда токен от BotFather
           GEMINI_KEY_1=сюда первый ключ
           GEMINI_KEY_2=сюда второй ключ

        Кавычки не нужны. Пробелы вокруг знака = не нужны.
        Сохранить (Ctrl+S) и закрыть.

Шаг 3.  Двойной клик по файлу       ЗАПУСК.bat

Шаг 4.  Открыть своего бота в телеграме, написать  /start


КАК ЗАПУСТИТЬ  (Linux / macOS)
───────────────────────────────────────────────────────
    bash install.sh
    nano .env          (вписать токен и ключи)
    npm run dev


ПРОВЕРИТЬ КЛЮЧИ, НЕ ЗАПУСКАЯ БОТА
───────────────────────────────────────────────────────
    npm run chat

Чат с продавцом прямо в консоли, без телеграма.
Отвечает — значит ключи рабочие.

    npm run rotation-demo

Специально выбивает ошибку лимита, чтобы показать,
как бот переключает ключи и модели.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
───────────────────────────────────────────────────────
"Ни один ключ не работает"
    Ключ скопирован не целиком или в кавычках.
    Кавычки в файле .env не нужны.

"Модели такой не существует"
    Google переименовал модели. Открыть
    https://aistudio.google.com → Models,
    взять актуальные имена и вписать в строку
    MODEL_CASCADE в файле .env

"Telegram не принял токен"
    Токен нужен целиком: 1234567890:AAH...

Бот отвечает ДВАЖДЫ на одно сообщение
    Запущены две копии. Закрыть окно мало —
    бот остаётся работать в фоне.
    Останавливать только через Ctrl+C в окне запуска.

Все ключи постоянно заняты
    Запросов больше, чем бесплатных квот.
    Завести ещё пару проектов в AI Studio.

Подробное описание — в файле README.md


ТО ЖЕ САМОЕ БЕЗ .BAT-ФАЙЛОВ
───────────────────────────────────────────────────────
Открыть папку с проектом, в адресной строке проводника
набрать  cmd  и нажать Enter. В открывшемся окне:

    npm install
    npm run seed
    copy .env.example .env
    notepad .env            (вписать токен и ключи)
    npm run dev

Остановить бота — Ctrl+C в этом же окне.
