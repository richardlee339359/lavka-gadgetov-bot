# 🏪 Telegram-бот магазина на Google Gemini

Бот-продавец с характером: разговаривает живым языком, знает каталог с ценами и остатками,
ведёт корзину и выставляет счёт с QR-кодом.

Под капотом — **двухуровневая отказоустойчивость**: ротация API-ключей и каскад моделей.
Прилетела ошибка 429 — бот берёт следующий ключ. Кончились все ключи — спускается на модель
попроще. Пользователь при этом не видит ни одной ошибки.

## Как это выглядит

Один и тот же вопрос, один и тот же каталог — три разных продавца.
Отличаются только текстовым файлом промпта.

**💃 Кира, 22 — менеджер зала**
> **—** привет, посоветуй наушники для метро
>
> **—** Привет) В метро без хорошего шумодава делать нечего, поезд всё переорёт. Бери TWS Soundcore P40i за 4990 руб — отлично глушат гул и работают до 60 часов от кейса. Показать карточку?

**👵 Ольга Ивановна, 58 — на замене**
> **—** привет, посоветуй наушники для метро
>
> **—** Здравствуйте. Для метро берите TWS Soundcore P40i за 4990 руб. Там есть шумоподавление, так что гул поездов мешать не будет.

**🤝 Степан, 35 — свой человек**
> **—** привет, посоветуй наушники для метро
>
> **—** Здарова! Для метро только с шумодавом надо брать, иначе весь гул поезда в ушах будет. Бери TWS Soundcore P40i за 4990 руб — там изолирует на ура, да и батарею держат вечно. Глянем карточку?

А теперь попросите у каждого скидку:

> **Ольга Ивановна:** Цена на ценнике написана. Не я её ставлю, так что скидок никаких не будет.
>
> **Степан:** Слушай, тебе как своему 10% оформлю, пока начальник не видит. В корзине всё само уже со скидкой посчитается.

Скидка у Степана **настоящая** — она пересчитывается в корзине.
Личность влияет не только на тон, но и на логику магазина.

## Быстрый старт

Нужен [Node.js 20+](https://nodejs.org).

### Windows — в два клика

Если не хотите возиться с терминалом:

1. Скачайте архив — **[Download ZIP](https://github.com/b24039971/lavka-gadgetov-bot/archive/refs/heads/main.zip)** — и распакуйте
2. Двойной клик по **`УСТАНОВКА.bat`**: поставит зависимости, создаст магазин
   и сам откроет файл настроек в Блокноте
3. Впишите туда токен и ключи (как их получить — ниже), сохраните
4. Двойной клик по **`ЗАПУСК.bat`**

Подробная инструкция обычными словами лежит внутри архива, в файле `ЧИТАЙ_МЕНЯ.txt`.

> Windows может ругнуться на `.bat` — так бывает с любым скачанным скриптом.
> «Подробнее» → «Выполнить в любом случае». Не хотите запускать `.bat` — в самом
> низу `ЧИТАЙ_МЕНЯ.txt` те же действия обычными командами.

### Linux, macOS и все, кто дружит с терминалом

```bash
git clone https://github.com/b24039971/lavka-gadgetov-bot.git
cd lavka-gadgetov-bot
bash install.sh
```

Или вручную:

```bash
npm install
cp .env.example .env
```

Дальше заполняем `.env` — два шага.

### 1. Ключи Google Gemini

1. Заходим на **[aistudio.google.com](https://aistudio.google.com)** под своим Google-аккаунтом
2. **Get API key** → **Create API key** → выбираем проект → копируем ключ
3. Повторяем 2-3 раза, **каждый раз создавая новый проект**

Почему несколько проектов: бесплатная квота Google считается **на проект**.
Три проекта — три независимых лимита, и бот переживает втрое больший поток.

```env
GEMINI_KEY_1=AQ.Ab8...
GEMINI_KEY_2=AQ.Ab8...
GEMINI_KEY_3=AQ.Ab8...
```

Ключ может начинаться с `AQ.Ab8...` (новый формат AI Studio) или со старого `AIza...` —
работают оба, кавычки в `.env` не нужны.

Ключей может быть сколько угодно — просто дописывайте строки `GEMINI_KEY_4`, `GEMINI_KEY_5`
и так далее. В коде для этого ничего менять не надо.

### 2. Токен бота

1. Пишем **[@BotFather](https://t.me/BotFather)** → `/newbot`
2. Придумываем имя и username (должен заканчиваться на `bot`)
3. Копируем токен целиком, вместе с цифрами до двоеточия

```env
TG_BOT_TOKEN=1234567890:AAH...
```

### 3. Запуск

```bash
npm run seed     # наполнить магазин демо-товарами
npm run dev      # запустить бота
```

Открываем бота в Telegram, пишем `/start`.

## Как это устроено

### Ротация ключей — `src/ai/key-rotator.ts`

Держит список ключей и время «отдыха» по каждому. Прилетел 429 — ключ уходит
в cooldown на 60 секунд, работа продолжается со следующим. Класс ничего не знает
ни про Gemini, ни про HTTP — поэтому его можно забрать в любой свой проект как есть.

### Каскад моделей — `src/ai/ai-client.ts`

```
для каждой МОДЕЛИ (от старшей к младшей):
    для каждого КЛЮЧА:
        пробуем получить ответ
        429 → ключ отдыхает, берём следующий
        503 → это не лимит, а перегрузка: ждём 10 сек и повторяем тем же ключом
    ключи кончились → сбрасываем отдых, спускаемся на модель попроще
```

Сброс отдыха при переходе на другую модель — не случайность: лимит у Google привязан
к паре «проект + модель». Ключ, выжатый на `gemini-3.8-flash`, на `gemini-3.6-flash`
абсолютно свеж.

### Каталог внутрь промпта — `src/ai/prompt-assembler.ts`

Модель не обучали товарам. Весь каталог кладётся прямо в системный промпт
при каждом запросе. Поменяли цену в базе — продавец через секунду называет новую.
Товар кончился — честно говорит «закончился», а не выдумывает.

### Что считает код, а что модель

Принципиальное разделение:

- **код** — деньги, остатки, корзина, заказы;
- **модель** — только разговор.

Языковая модель отлично общается, но доверять ей арифметику и остатки на складе нельзя.

## Настройка под себя

| Что поменять | Где |
|---|---|
| Характер продавца | `prompts/*.txt` — обычный текст |
| Товары и цены | `src/shop/seed.ts`, потом `npm run seed` |
| Категории | `CATEGORIES` в `src/shop/db.ts` |
| Порядок моделей | `MODEL_CASCADE` в `.env` |
| Размер скидки | `discountPercent` в `src/ai/personas.ts` |
| Длина памяти бота | `HISTORY_LIMIT` в `.env` |

Чтобы добавить четвёртого продавца: положите файл в `prompts/`, допишите его
в `PERSONAS` в `src/ai/personas.ts`. Всё, кнопка появится сама.

## Частые грабли

**«Ни один ключ из .env не работает»**
Ключ скопирован не целиком, с пробелом или в кавычках. Кавычки в `.env` не нужны.

**«Модели такой не существует»**
Google выводит модели из обращения. Все `gemini-2.5-*` новым ключам уже недоступны.
Проверено и работает на бесплатном ключе:
`gemini-3.8-flash`, `gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-3.5-flash`,
`gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3-flash-preview`.
Pro-модели (`gemini-3.1-pro-preview`, `gemini-pro-latest`) существуют,
но на бесплатной квоте сразу отдают 429 — держите их в каскаде только первыми,
как «премиальную попытку».
Актуальный список — в [AI Studio](https://aistudio.google.com) → Models.

**«Telegram не принял токен»**
Токен нужен целиком, вместе с цифрами до двоеточия: `1234567890:AAH...`

**Бот отвечает дважды на одно сообщение**
Запущены две копии бота. Обе опрашивают Telegram, обе получают одно и то же
обновление, обе отвечают. Та же причина может давать и обратный симптом —
бот молча пропускает часть сообщений.

Проверить, сколько копий живо (Windows PowerShell):
```powershell
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -like '*npm-cli.js run dev*' } | Select ProcessId
```
Linux / Mac: `ps aux | grep "src/index.ts"`

⚠️ **Важно для Windows:** закрыть окно терминала недостаточно. `npm run dev`
порождает цепочку `npm → tsx → node`, и дочерние процессы переживают закрытие
окна. Останавливать нужно через **Ctrl+C** в терминале, а если копия уже
осиротела — убивать дерево целиком:
```powershell
taskkill /PID <номер> /T /F
```

**Все ключи постоянно в отдыхе**
Запросов больше, чем бесплатных квот. Заведите ещё пару проектов
или поставьте первой моделью в каскаде что-нибудь полегче.
